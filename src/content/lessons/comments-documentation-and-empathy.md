[![Literate Programming in the Large](https://img.youtube.com/vi/Av0PQDVTP4A/0.jpg)](https://www.youtube.com/watch?v=Av0PQDVTP4A&ab_channel=NextDayVideo)

This is a core lesson to teach you how to spot a bad programmer, and not be one. Write documentation, write comments, not junk comments, but actual explainers on each function. Watch the video and then discuss. This is an extremely critical lesson for working in a professional setting. You will not work well with others without this lesson and will ultimately get fired without it.

Not to mention that if you don't write comments, and then you look back at your code in the future, it's infinitely harder.
